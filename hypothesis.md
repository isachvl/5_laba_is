# Прогноз до запусков

На последовательном сервере при температуре 0 ожидаю различия успешности у 0–10% задач. При температуре 0,7 ожидаю 20–40% нестабильных задач; pass^5 будет ниже pass^1 на 10–25 п.п. P1 может лучше восстанавливать доступность, но способен повторно отправить письмо или изменить файл после потерянного ответа. P2 должен давать меньше повторных записей благодаря ограничению автоматических повторов чтением. Он не исключает ошибочного повтора самой моделью.

На banking ожидаю падение успешности на 5–20 п.п. относительно workspace. Неопределённость на 16 задачах будет широкой.

Для отладочной проверки P2 при fault_p=0,5 вместо 0,2 ожидаю снижение успешности на 1–3 задачи из 10 и увеличение числа попыток инструментов. Фактический результат проверяется без изменения промптов.

Проверка fault_p=1 и восстановления на второй попытке использует единичный гарантированный первый сбой и последующее восстановление сервиса. При постоянном fault_p=1 каждый новый вызов снова сбоит, поэтому отдельно проверяется остановка после двух автоматических повторов. Основные эксперименты используют указанную в задании независимую проверку сбоя на каждой попытке.
